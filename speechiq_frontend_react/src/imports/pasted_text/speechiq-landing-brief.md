### Design notes for Figma Make
- All cards: white background, `border-radius: 20px`, `border: 1px solid #E5E7EB`, subtle shadow `0 2px 12px rgba(0,0,0,0.06)`
- Section spacing: generous — 120px vertical padding between sections
- Typography: Inter font family throughout. Headlines 48–64px bold. Body 16px regular. Sub-labels 12px medium.
- Phone mockups: use rounded-corner frames (iPhone-style), slight perspective tilt on the hero. Soft purple glow behind hero phone.
- The XP progress bar, score bars, and waveform in feature illustrations should use the actual purple gradient, not placeholder colours.
- Gamification elements (streak badge, XP chips, achievement badges) should use the amber/orange palette to contrast against the purple primary.
- Voice Lab feature card and CTA should always use the emerald→teal gradient to visually distinguish it as premium.
- Mobile layout: all two-column rows stack vertically, phone mockups go above their copy block, navigation collapses to hamburger.
